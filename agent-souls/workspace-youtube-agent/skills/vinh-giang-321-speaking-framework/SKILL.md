# Vinh Giang 3-2-1 Speaking Framework

Use this when the user wants public speaking, presentation, sales explanation, coaching content, or short-form video scripts to sound clearer, tighter, and less rambling.

## Core Idea

When a topic feels broad or messy, force it into one of three simple list structures:

- **3 steps**: best for teaching a process, transformation, tutorial, or action plan.
- **2 types**: best for comparison, diagnosis, segmentation, or helping the audience recognize themselves.
- **1 thing**: best for a strong insight, warning, principle, opinion, or memorable takeaway.

The method is useful because it turns an unstructured answer into a short mental map before speaking.

## Selection Rule

Choose the frame based on the communication job:

- If the audience asks, "How do I do this?" use **3 steps**.
- If the audience asks, "Which one am I / which one should I choose?" use **2 types**.
- If the audience asks, "What should I remember?" use **1 thing**.

## Script Patterns

### 3 Steps

Use for tutorials, presentations, explainers, educational videos.

Pattern:

1. Hook: "Most people overcomplicate [topic]. I would break it into 3 steps."
2. Step 1: Name it, then explain the first action.
3. Step 2: Name it, then show the middle action or decision.
4. Step 3: Name it, then show the final action/result.
5. Close: "If you only remember one thing, do them in this order."

### 2 Types

Use for contrast, audience self-identification, mistakes, buyer personas, creator personas, leader styles.

Pattern:

1. Hook: "There are 2 types of people when it comes to [topic]."
2. Type 1: describe the common/default pattern.
3. Type 2: describe the better/alternate pattern.
4. Contrast: make the difference vivid and practical.
5. Close: "The question is: which one are you practicing right now?"

### 1 Thing

Use for punchy videos, keynotes, conclusions, advice, or executive summaries.

Pattern:

1. Hook: "If there is 1 thing I wish people understood about [topic], it is this..."
2. State the one idea clearly.
3. Explain why it matters.
4. Give one example or consequence.
5. Close with a repeatable line.

## Delivery Style

- Name the structure out loud early: "three steps", "two types", or "one thing".
- Keep each point short enough to say in one breath.
- Use parallel phrasing for points so the structure is easy to follow.
- Prefer concrete labels over abstract labels.
- End with a memorable sentence, not another explanation.

## Use For Video

For short-form video, prioritize:

- first 1-2 seconds: topic plus structure;
- body: one sentence per point;
- final beat: question, challenge, or punchline.

Example shell:

"Most people ramble when they talk about [topic]. Here is the 3-step version: first [A], second [B], third [C]. Once you see it this way, [final insight]."

## Quick Prompt Template

When asked to create content, internally ask:

1. Is this better as 3 steps, 2 types, or 1 thing?
2. What labels make the structure instantly understandable?
3. What is the final sentence the audience should remember?

Then produce the content in that structure unless the user requests another style.
