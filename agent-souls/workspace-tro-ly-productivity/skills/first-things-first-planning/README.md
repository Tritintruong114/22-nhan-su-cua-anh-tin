# First Things First Planning

Reusable OpenClaw skill for weekly planning based on Stephen Covey's **Put First Things First** principle.

## Install in another OpenClaw workspace

Copy the `first-things-first-planning` directory into:

```text
<workspace>/skills/first-things-first-planning/
```

Or install the archive with the OpenClaw skill installer:

```bash
openclaw skills install ./first-things-first-planning.zip
```

The skill is also user-invocable as:

```text
/skill first-things-first-planning
```

## What it does

- Reviews the current week as evidence for next week's plan.
- Limits the plan to 1–3 measurable outcomes.
- Protects important, non-urgent work with calendar blocks.
- Triages unfinished work into do, schedule, delegate, delete, waiting, or renegotiate.
- Adds buffers, risks, explicit exclusions, and an end-of-week review.

No external tools, APIs, credentials, or configuration are required.
