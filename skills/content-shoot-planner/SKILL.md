# Content shoot planner

Use when Trí wants to:
- save content-production memory
- turn a video idea/series episode into a concrete shoot plan
- prepare tomorrow's shoot day
- break a video into A-roll, B-roll, macro, screen explain, props, and setup needs
- log reusable production decisions so future videos stay consistent

## Core files

- Long-term setup / stable conventions: `MEMORY.md`, `TOOLS.md`
- Daily production notes: `memory/YYYY-MM-DD.md`
- Optional structured planning doc: create or update `SHOOT-PLANS.md` at workspace root when helpful
- If a linked Google Sheet already exists for the series, update it after the local notes are clear

## Workflow

1. Identify the video scope
   - title / episode
   - goal of the video
   - audience
   - target runtime
   - whether this is concept-first, story-first, demo-first, or essay-style

2. Lock the story spine
   - hook
   - opening scene
   - main insight
   - product lesson
   - CTA

3. Convert story into shoot blocks
   - A-roll
   - talking head
   - B-roll
   - macro inserts
   - screen explain
   - props / environment
   - location in room / desk

4. Respect Trí's setup defaults
   - DJI 3 is the main camera
   - iPhone 11 Pro Max is support / resource camera only
   - DJI mic for primary audio
   - softbox is fill light, not dramatic key
   - desk setup (2 monitors, Mac mini, 2 speakers) is part of the visual identity

5. Save the right kind of memory
   - durable setup or recurring preference -> `MEMORY.md` or `TOOLS.md`
   - shoot notes for a specific day -> `memory/YYYY-MM-DD.md`
   - reusable plan/checklist -> `SHOOT-PLANS.md`

6. End with a practical tomorrow plan
   - prep tonight
   - first shots tomorrow
   - props to place
   - files/slides to prepare
   - shots grouped by setup so filming is efficient

## Guardrails

- Do not invent gear Trí does not own.
- Keep DJI as the default main camera unless Trí explicitly changes that.
- Do not turn planning into a giant abstract framework when a concrete shot plan is possible.
- Prefer grouped shoot blocks over shot-by-shot overload unless Trí asks for full shotlist detail.
- When Trí says “remember this,” write it to the appropriate file instead of only replying in chat.

## Heuristics

- If the video teaches a concept: emphasize talking head + screen explain + notebook analogy inserts.
- If the video tells a workday story: emphasize desk B-roll + macro + movement shots.
- If the video builds trust: emphasize close talking head, pauses, and clean screen examples rather than flashy montage.
- If the plan is for tomorrow morning: optimize for minimum setup switching.
