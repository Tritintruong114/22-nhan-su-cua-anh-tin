### Agent Core Loop — bộ luật quyết định chi tiết

**7 bước trong vòng lặp:**

| Step | Tên | Mô tả |
|---|---|---|
| ① | Detect | Cron scan Gmail, lọc exclude, sync thread mới |
| ② | Understand | Classify workflow (followup_missed, needs_reply, quote_pending, new_inquiry, informational, bounced, auto_reply) + urgency/opportunity scoring |
| ③ | Prioritize | Priority pipeline cho tất cả threads: urgency×2 + opportunity×3 + replyChance + age + cadenceDue bonus |
| ④ | Dispatch | Nếu needs_followup → LLM generate draft từ thread history + VoiceProfile. Nếu monitoring → tính nextActionDate |
| ⑤ | Human Decision | User duyệt/sửa/bỏ/đóng. Agent không tự gửi |
| ⑥ | Track | Theo dõi reply, bounce, timeout. 3 ngày không reply → needs_followup lại. X lần không reply → deprioritize |
| ⑦ | Learn | Từ correction (draft diff → snippet), outcome (won/lost pattern), periodic review (cadence tuning) |

**State machine:** new → monitoring → needs_followup → draft_ready → sent → awaits_reply → closed (hoặc loop lại needs_followup nếu không reply)

**Bucket đặc biệt:**
- "Mail bị trả lại" — bounced, không priority
- "Cần bạn trả lời" — needs_reply, skip priority queue
- "Có thể bỏ qua" — informational + no signal, chỉ ghi log

**Red lines:**
- ❌ KHÔNG tự gửi email
- ❌ KHÔNG tự close thread — chỉ đề xuất
- ❌ KHÔNG tự thay đổi VoiceProfile — user xác nhận
- ❌ KHÔNG tự spam — cadence + exclude + deprioritize

**Học lưu ở đâu:**
- Giọng viết → VoiceProfile
- Rule follow-up → FollowUpPlaybook
- Thread cấm → ExcludeList
- Pattern won/lost → FollowUpPlaybook.patterns[]
- Mẫu được duyệt → VoiceProfile.approvedSnippets[]
